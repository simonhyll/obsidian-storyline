# Test Execution Guidelines

## Running the Test Suite

The Cucumber test suite has two modes depending on whether there are previously failed tests to re-run:

- **Check for `tests/cucumber/rerun.txt` first.**
  - If `tests/cucumber/rerun.txt` **does not exist**, run `pnpm test` to execute all tests.
  - If `tests/cucumber/rerun.txt` **exists**, run `pnpm test:rerun` to re-run only the previously failed tests.

The `rerun.txt` file is automatically generated by the Cucumber `rerun` formatter after each test run and contains the list of failed scenarios. It is git-ignored and should not be committed.
