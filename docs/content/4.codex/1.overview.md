The Codex is your central repository for all reference materials in your story world. It includes characters, locations, and any custom categories you create.

## What Is the Codex?

The Codex organizes all the non-scene elements of your story:

- **Characters** — People, creatures, and entities in your story
- **Locations** — Places, worlds, and settings
- **Custom Categories** — Any other reference material you define

Each codex entry is a Markdown note with frontmatter metadata, stored in your project's Codex folder.

## Codex Hub

The Codex Hub provides a central entry point to browse all codex entries. It organizes entries by category and allows quick navigation.

## Linking

Codex entries are linked using standard Obsidian wikilinks:

- Link characters and locations from scenes
- Link between codex entries (e.g., character to location)
- Link from scenes to any codex entry

Störyline automatically detects these links and builds a network of cross-entity references.

## Cross-Entity References

The link scanner detects all wikilinks between scenes and codex entries, providing:

- **Character appearances** — See which scenes each character appears in
- **Location usage** — See which scenes take place at each location
- **Relationship map** — Visualize connections between characters

## Custom Codex Categories

Create custom categories beyond characters and locations:

- Organizations, factions, or groups
- Items, artifacts, or weapons
- Magic systems, technologies, or rules
- Historical events or timelines

Each custom category gets its own folder and can have custom fields.

## Managing Fields

Customize the fields shown for each codex category:

- **Hide/show built-in fields** — Control which default fields are visible
- **Add custom fields** — Create project-specific metadata
- **Reorder fields** — Arrange fields in your preferred order
- **Reorder sections** — Group fields into sections

## Image Galleries

Attach images to codex entries:

- Character portraits
- Location maps
- Concept art
- Reference images
