The Characters View lets you browse, create, and manage character profiles for your story. Each character is stored as a Markdown note with rich metadata.

## Character Profiles

Each character profile can include:

- **Name** — Display name of the character
- **Description** — Brief summary of the character
- **Notes** — Detailed notes about personality, motivations, backstory
- **Relationships** — Links to other characters
- **Appearance in scenes** — Which scenes the character appears in
- **Custom fields** — Project-specific metadata

## Managing Characters

- **Create** — Add new characters from the Characters View
- **Edit** — Open character notes in the Obsidian editor
- **Link to scenes** — Associate characters with scenes using wikilinks
- **Relationship Map** — Visualize character relationships interactively

## Cross-Entity References

Störyline automatically detects wikilinks between characters and scenes, building a network of cross-entity references. Use this to:

- Find all scenes where a character appears
- See which characters interact with each other
- Identify characters that may need more development

## Codex Linking

Characters are part of the Codex system. They can be linked from scenes, locations, and other codex entries using standard Obsidian wikilinks.
