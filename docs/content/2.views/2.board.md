The Board View is the primary workspace in Störyline. It displays all your scenes as visual cards, organized by plotlines, allowing you to see and rearrange your story at a glance.

## Layout

The Board View organizes scenes into columns, where each column represents a plotline. Scene cards within each column can be reordered to control the reading order of your story.

## Scene Cards

Each scene card displays:

- **Scene title** — The main identifier for the scene
- **Subtitle** — Optional secondary description
- **Word count** — Current word count of the scene
- **Characters** — Characters appearing in the scene
- **Date/Time** — When the scene takes place
- **Color coding** — Visual color based on plotline or custom settings
- **Status indicators** — Active, inactive, or archived status

## Interactions

- **Drag and drop** — Rearrange scenes within and between plotlines
- **Click** — Open the scene in the editor
- **Right-click** — Access context menu with quick actions
- **Multi-select** — Select multiple scenes for bulk editing

## Corkboard Mode

Toggle Corkboard Mode to see a more compact, sticky-note-style view of your scenes. This mode supports custom sticky note themes and color overrides.

## Filtering

Use the filter bar to narrow down visible scenes by:

- Plotline
- Characters
- Tags
- Date range
- Custom presets

Save frequently used filters as **Presets** for quick access.

## Keyboard Shortcuts

- `Ctrl+Shift+N` — Create new scene
- `Delete` — Remove selected scene(s)
- `Arrow keys` — Navigate between scenes
- `Enter` — Open selected scene
