The Locations View helps you manage places in your story world. Each location is stored as a Markdown note with metadata and notes.

## Location Profiles

Each location can include:

- **Name** — Display name of the location
- **Description** — Brief summary of the place
- **Notes** — Detailed description, history, and significance
- **Appearance in scenes** — Which scenes take place at this location
- **Custom fields** — Project-specific metadata

## Managing Locations

- **Create** — Add new locations from the Locations View
- **Edit** — Open location notes in the Obsidian editor
- **Link to scenes** — Associate locations with scenes using wikilinks

## Codex Linking

Locations are part of the Codex system. They can be linked from scenes, characters, and other codex entries using standard Obsidian wikilinks.
