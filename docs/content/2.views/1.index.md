## Switching Between Views

Use the tab bar at the top of any Störyline view to switch between different perspectives. Each view shares the same underlying data, so changes made in one view are immediately reflected in all others.

## Scene Details Sidebar

Most views support a **Scene Details Sidebar** that shows detailed metadata for the selected scene. Open it by clicking on a scene card or using the sidebar toggle.

## Research Sidebar

The **Research Sidebar** lets you keep reference materials open while writing, without leaving your current view.
