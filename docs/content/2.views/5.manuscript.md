The Manuscript View lets you read your scenes in reading order as a continuous flow, simulating the final manuscript experience.

## Reading Order

Scenes appear in the order you've set in the Board View. This is the **reading order**, which may differ from the chronological order shown in the Timeline View.

## Features

- **Continuous reading** — Scenes flow one after another without interruption
- **Scene navigation** — Jump between scenes using the scene list
- **Word count** — See total and per-scene word counts
- **Writing Sprint** — Focus mode for writing sessions

## Writing Sprint

Enter Writing Sprint mode to focus on writing without distractions:

- Hides all UI elements except the current scene
- Tracks your writing progress in real-time
- Shows word count goals and completion percentage

## Scene Management

From the Manuscript View you can:

- Reorder scenes by dragging
- Mark scenes as inactive or archived
- Add new scenes at the current position
- Open scenes in the editor for editing
