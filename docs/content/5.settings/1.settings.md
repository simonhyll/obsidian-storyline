## Project Management

Störyline supports multiple projects within a single Obsidian vault. Each project has its own folder structure, scenes, and codex.

### Creating Projects

1. Open the command palette (`Ctrl+P` / `Cmd+P`)
2. Run **StoryLine: Create New Project**
3. Enter a project title and configure options

### Project Hierarchy

Projects can be organized in a hierarchy for series or multi-book projects:

- **Series Mode** — Group multiple books under a series
- **Shared Codex** — Share characters and locations across books
- **Per-project settings** — Customize each project independently

## Export

Export your manuscript in various formats:

- **PDF** — Export as a formatted PDF document
- **Markdown** — Export scenes as Markdown files
- **Custom formats** — Configure export templates

## Import

Import content from other writing tools:

- **Scrivener** — Import Scrivener bundles (.scriv or .zip)
- Map Scrivener folders to plotlines
- Preserve scene content and structure

## Customization

### Color Coding

- **Plotline HSL sliders** — Fine-tune plotline colors
- **Scene colors** — Override individual scene colors
- **Tag colors** — Color scenes by tags
- **Sticky note themes** — Customize corkboard appearance
- **Per-project color overrides** — Different colors per project

### Fields and Sections

- **Hide/show built-in fields** — Control visible fields
- **Reorder fields** — Arrange field order
- **Reorder sections** — Group fields into sections
- **Custom fields** — Add project-specific metadata
- **Tag type overrides** — Override how tags are interpreted

## Keyboard Shortcuts

Configure keyboard shortcuts for common actions:

- `Ctrl+Shift+N` — Create new scene
- `Ctrl+P` — Open command palette
- Custom shortcuts for frequently used commands

## Additional Source Folders

Add additional folders to your project beyond the default structure:

- Include scenes from other folders
- Reference notes outside the project folder
- Custom organizational structures

## File Structure

Störyline uses the following file structure:

```
StoryLine/
  Project Name/
    Scenes/
      scene-1.md
      scene-2.md
    Codex/
      Characters/
        character-1.md
      Locations/
        location-1.md
```

All data is stored as plain Markdown files with YAML frontmatter, making it easy to back up, version control, or edit outside Obsidian.
