## Filtering & Presets

Use the filter bar to narrow down visible scenes by various criteria:

- **Plotline** — Show only scenes from specific plotlines
- **Characters** — Filter by character presence
- **Tags** — Filter by scene tags
- **Date range** — Show scenes within a date range
- **Custom fields** — Filter by custom field values

### Saving Presets

Save frequently used filter combinations as presets for quick access. Presets are stored per-project and appear in the filter dropdown.

## Multi-Select & Bulk Edit

Select multiple scenes to perform bulk operations:

- **Move to plotline** — Change plotline for multiple scenes
- **Add/remove characters** — Update character lists
- **Change tags** — Add or remove tags
- **Archive/restore** — Change scene status
- **Delete** — Remove multiple scenes

## Color Coding

Color-code scenes for visual organization:

- **Plotline colors** — Automatic coloring based on plotline assignment
- **Scene colors** — Manual color override for individual scenes
- **Tag colors** — Colors derived from scene tags
- **Plotline HSL sliders** — Fine-tune plotline colors

## Reading Order vs. Chronological Order

Störyline maintains two separate orderings:

- **Reading Order** — The order scenes appear in the final manuscript (Board View, Manuscript View)
- **Chronological Order** — The actual timeline order of events (Timeline View)

Reorder scenes in the Board View to set reading order. Set dates on scenes to control chronological order.

## Setup / Payoff Tracking

Mark scenes as containing setups or payoffs for plot threads:

- Track which scenes introduce elements (setups)
- Track which scenes resolve elements (payoffs)
- Identify unresolved setups that may become plot holes

## Plot Hole Detection

Störyline can detect potential plot holes by analyzing setup/payoff pairs:

- Unresolved setups are flagged as potential plot holes
- Review flagged scenes to resolve or dismiss issues
