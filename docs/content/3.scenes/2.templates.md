## Scene Templates

Scene templates let you create new scenes with a consistent structure. Define default frontmatter fields and boilerplate content that is applied automatically.

### Creating Templates

1. Create a Markdown file with your desired structure
2. Include frontmatter with default values
3. Add any boilerplate content
4. Select the template when creating a new scene

### Template Example

```yaml
---
title: "New Scene"
plotline: ""
characters: []
location: ""
date: ""
---

## Summary


## Draft


## Notes

```

## Beat Sheet Templates

Beat sheet templates help you structure your story using proven narrative frameworks:

- **Save the Cat** — 15 beat sheet structure
- **Seven Point Story Structure** — Key plot points
- **Fichtean Curve** — Rising action through crises
- **Custom Templates** — Create your own beat structure

Apply beat sheet templates to your project to guide scene creation and ensure structural balance.

## Custom Field Templates

Define templates for custom fields in your project:

- Set default values for custom fields
- Create field groups for different scene types
- Apply templates to existing scenes
