Scene cards are the core building blocks of your story in Störyline. Each scene is stored as a Markdown file with frontmatter metadata, displayed as a visual card in the Board View.

## Creating Scenes

- Use `Ctrl+Shift+N` or the **+** button in the Board View
- Use the **Quick Add Modal** for fast scene creation
- Scenes are created in the current project's Scenes folder

## Scene Metadata

Each scene card displays key information from the scene's frontmatter:

- **Title** — The scene's main identifier
- **Subtitle** — Optional secondary description
- **Plotline** — Which plotline the scene belongs to
- **Characters** — Characters appearing in the scene
- **Location** — Where the scene takes place
- **Date/Time** — When the scene occurs in the story
- **Word count** — Current word count
- **Status** — Active, inactive, or archived

## Editing Scenes

- **Inspector Panel** — Edit metadata without leaving the editor
- **Frontmatter** — Edit YAML frontmatter directly in the Markdown file
- **Scene Card** — Click and edit directly from the Board View

## Scene Filename Synchronization

Enable this feature to automatically keep scene filenames in sync with scene titles. When you change a scene's title, the filename is updated to match.

## Scene Subtitles

Add subtitles to scenes for additional context. Subtitles appear below the title on scene cards and in the Manuscript View.

## Scene Archive

Archive scenes you want to keep but remove from active views. Archived scenes are hidden from most views but can be restored.

## Inactive Scenes

Mark scenes as inactive to temporarily hide them without archiving. This is useful for scenes you're unsure about or planning to rewrite.

## Scene Templates

Create templates for consistent scene structure:

- Define default frontmatter fields
- Include boilerplate content
- Apply templates when creating new scenes

See [Scene Templates](/scenes/templates) for more details.

## Custom Scene Fields

Add custom fields to scenes beyond the built-in metadata:

- Create custom fields in project settings
- Define field types and default values
- Use custom fields in scene cards and the inspector

## Scene Notes

Add private notes to scenes that don't appear in the final manuscript. Use notes for:

- Writing reminders
- Revision ideas
- Research references

## Arc Points

Mark important story beats on scenes:

- Inciting incident
- Plot points
- Climax
- Resolution

Arc points help you track the structural elements of your story.

## Scene Snapshots

Save snapshots of scene metadata to track changes over time. Restore previous versions or compare changes.

## Splitting and Merging Scenes

- **Split** — Divide a scene into two separate scenes
- **Merge** — Combine two scenes into one
