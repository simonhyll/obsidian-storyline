## Prerequisites

- [Obsidian](https://obsidian.md/) installed on your system

## Manual Installation

1. Download the latest release files:
   - `main.js`
   - `manifest.json`
   - `styles.css`

2. Copy these three files into your vault at `.obsidian/plugins/StoryLine/`:
   ```
   YourVault/
     .obsidian/
       plugins/
         StoryLine/
           main.js
           manifest.json
           styles.css
   ```

3. Open Obsidian → **Settings → Community Plugins** → enable **StoryLine**

4. Restart Obsidian

## Installation from Source

1. Clone or download this repository into `.obsidian/plugins/StoryLine/`

2. Install dependencies and build:
   ```bash
   pnpm install
   pnpm run build
   ```

3. Enable the plugin in Obsidian settings

4. Restart Obsidian

## Verifying Installation

After installation, you should see:

- **StoryLine** listed in **Settings → Community Plugins** as enabled
- The **StoryLine** command in the command palette (`Ctrl+P` / `Cmd+P`)
- A **StoryLine** ribbon icon in Obsidian

:::tip
If you don't see the plugin, make sure the files are in the correct directory and restart Obsidian.
:::
