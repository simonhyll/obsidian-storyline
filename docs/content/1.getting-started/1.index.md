Störyline transforms your Obsidian vault into a full-featured book planning and writing tool. Organize scenes, build rich character profiles, manage worlds and locations, track plotlines, and monitor your progress — all without leaving Obsidian.

:::tip
Störyline is based on [StoryLine by Jan Sandström](https://github.com/PixeroJan/obsidian-storyline). Please consider supporting the original author with a [donation](https://www.paypal.com/donate?hosted_button_id=A2N2LE7EUBL3A).
:::

## Key Features

- **Scene Cards** — Organize your story with visual scene cards containing metadata, notes, and custom fields
- **Multiple Views** — Board, Timeline, Plotgrid, Manuscript, Characters, Locations, and more
- **Characters & Codex** — Build rich profiles for characters, locations, and any story element
- **Timeline & Events** — Track events with swimlanes, pacing analysis, and chronological ordering
- **Plotlines** — Track setup/payoff, detect plot holes, and manage story arcs
- **Export & Import** — Export your manuscript and import from Scrivener
- **Fully Theme-Aware** — Dark and light mode support that matches your Obsidian theme

## How It Works

Störyline stores all data as Markdown files in your Obsidian vault. When you create a project, it generates a folder structure:

```
StoryLine/
  My Novel/
    Scenes/
    Codex/
      Characters/
      Locations/
```

Every scene, character, and location is a regular Markdown note that you can edit in Obsidian or any text editor. Störyline reads the frontmatter and content to display rich views and tools.
