Follow these steps to create your first project and start writing.

## Step 1: Create a Project

1. Open the command palette (`Ctrl+P` / `Cmd+P`)
2. Run **StoryLine: Create New Project**
3. Give your project a title (e.g., "My Novel")

Störyline creates a folder structure for you:

```
StoryLine/
  My Novel/
    Scenes/
    Codex/
      Characters/
      Locations/
```

## Step 2: Create Your First Scene

1. Open the **Board View** for your project
2. Use `Ctrl+Shift+N` or click the **+** button
3. Fill in the scene title and any metadata
4. Start writing your scene content

## Step 3: Explore Views

Switch between views using the tab bar at the top of any Störyline view:

- **Board View** — Visual card layout of all scenes
- **Timeline View** — Chronological view of scenes and events
- **Plotgrid View** — Character-by-scene grid for tracking arcs
- **Manuscript View** — Read scenes in reading order
- **Characters View** — Manage character profiles
- **Locations View** — Manage location notes

## Step 4: Add Characters

1. Open the **Characters View**
2. Create a new character
3. Fill in the character profile with details, relationships, and notes

## Tips for Getting Started

- Use the **Inspector Panel** to edit scene metadata without leaving the editor
- Try the **Scene Templates** feature to create consistent scene notes
- Enable **Scene Filename Synchronization** to keep filenames in sync with scene titles
- Use **Keyboard Shortcuts** to speed up your workflow
